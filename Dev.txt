§3 公理系統（本回合真實設立，全局／局部）
  全局公理 G（伽羅瓦對應／極性）：
    有限集合 X,Y 與關係 R ⊆ X×Y。定義
      F(A) = { y∈Y | ∀x∈A, R(x,y) },  H(B) = { x∈X | ∀y∈B, R(x,y) }.
    伴隨性 A ⊆ H(B) ⟺ B ⊆ F(A)；c = F∘H 為 X 上閉包算子，
    c' = H∘F 為 Y 上閉包算子；閉集格 Fix(c) ≅ Fix(c')^op。
  局部公理（C1 自決，逐條為可執行定義，非斷言式口號）：
    L1 有限支撐公理：所有代數物件以有限索引集上的精確有理係數函數表示；
       稀疏表示省略零項；每環帶明確截斷次數 N。
    L2 卷積么半群公理：交換么半群 (M,*,e) 上 (a*b)(m) = Σ_{u*v=m} a(u)b(v)。
       多項式環 = (ℕ,+)；形式冪級數環 = (ℕ,+) 截斷；洛朗級數環 = (ℤ,+) 帶下界偏移；
       狄利克雷級數環 = (ℕ≥1,×)；多項式商環 = (ℕ,+) 模首一關係。
       此為「共性／多合一」之嚴格形式。
    L3 截斷商公理：π_N : ℚ[[t]] → ℚ[[t]]/(t^N) 為滿環同態；商環中係數 < N 精確；
       理想 I ⊇ (t^N) 與商環子環之間由標準 Galois 對應聯繫。
    L4 極性矩陣／楚空間公理：物件與屬性為二元矩陣之列／行；轉置為鏡像對偶；
       關係複合由布林矩陣乘法給出；沿索引映射之 Kan 擴展為纖維上的和／積。
    L5 有限域算術公理：模 p 運算以 Int64 + 擴展歐幾里得求逆；GF(2) 線性代數以
       UInt64 位元打包 + 消去法，對應硬體層級常數優化。
  形式化層：src/axioms 以 proof_enabled = true、.mbtp predicate/lemma、
    proof_require/proof_ensure 交予 Z3  discharge（非 stub、非空命題）。

§9 驗證過程與修正記錄（流水帳，誠實保留）
  - 形式化層最終不使用 proof_axiomatized／trusted assumption：早期版本引用 .mbt 內
    #proof_pure clamp/hcoeff/hilbert_delta，WhyML lowering 為無定義抽象函數，
    造成 12 proved / 3 timeout；移除該類述詞並把 closure_apply 主體改為 inline
    if x >= 0 { x } else { 0 } 後得 17 goals proved、0 timeout。
  - .mbtp predicate body 不支援 let / if / nested match 等寫法；大寫 lemma 名稱
    觸發 uppercase start 錯誤；最終改為 11 個小寫命名純整數／多項式恆等式 lemma。
  - 語法：for j = 0..<n 觸發 Range operators 僅支援 for .. in；必須寫 for j in 0..<n；
    範圍含運算式需括號 0..<(n-1)；Array 變數加 mut 觸發 unused_mut；
    guard 為保留字；函式型別需寫 (Int64) -> Rat。
  - ideal_variety_context(3L, 2) 之離線模擬顯示 F(H(V)) != V 對 V=3,5,6；
    p=3,deg=3 全部 V fixed，故測試改用 deg=3，並把 theorem_ideal_variety 的全枚举
    改為 cap = min(nx,12) 穷舉 + 伴隨性一般保證（避免 2^27 枚举）。
  - 定理陳述修正（由即時驗題發現，非事先假設）：原擬「Ext¹ 中間群同構型數
    = gcd(m,n)」為假——Python 與 MoonBit 交叉驗證顯示其為 τ(gcd(m,n))（g 的
    正因數個數）；不同擴張類可對應同構中間群。src/algebra/homological.mbt
    已改為 T-E1：擴張類 g 個、中間群同構型 τ(g) 個，並新增 divisor_count()。
  - 定理陳述修正（Kan 擴展伴隨）：薄範疇 [D,D] 中之 G 必須為函子（單調）；
    對任意函數 G 穷舉會使伴隨性失效。compose.mbt 加入 monotone_g 過濾後
    T-C1/T-C2 通過（Python 交叉驗證 576 組單調 G 全數吻合）。
  - Lagrange 反演驗題期望值修正：f=t/(1-t) 之逆為 t/(1+t)，[t^3] 係數為 +1
    （非 -1）；[t^2] 為 -1。
  - 其他：root README.md 原為指向已刪除 README.mbt.md 的 dangling symlink，
    已改為真正檔案；Dev.txt header 明確標注 Asia/Hong_Kong 與沙盒 UTC 時差。
