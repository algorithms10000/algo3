§3 公理系統（本回合真實設立，全局／局部）
  全局公理 G（伽羅瓦對應／極性）：
    有限集合 X,Y 與關係 R ⊆ X×Y。定義
      F(A) = { y∈Y | ∀x∈A, R(x,y) },  H(B) = { x∈X | ∀y∈B, R(x,y) }.
    伴隨性 A ⊆ H(B) ⟺ B ⊆ F(A)；c = F∘H 為 X 上閉包算子，
    c' = H∘F 為 Y 上閉包算子；閉集格 Fix(c) ≅ Fix(c')^op。
  局部公理（C1 自決，逐條為可執行定義，非斷言式口號）：
    L1 有限支撐公理：所有代數物件以有限索引集上的精確有理係數函數表示；
       稀疏表示省略零項；每環帶明確截斷次數 N。
    L2 卷積么半群公理：交換么半群 (M,*,e) 上 (a*b)(m) = Σ_{u*v=m} a(u)b(v)。
       多項式環 = (ℕ,+)；形式冪級數環 = (ℕ,+) 截斷；洛朗級數環 = (ℤ,+) 帶下界偏移；
       狄利克雷級數環 = (ℕ≥1,×)；多項式商環 = (ℕ,+) 模首一關係。
       此為「共性／多合一」之嚴格形式。
    L3 截斷商公理：π_N : ℚ[[t]] → ℚ[[t]]/(t^N) 為滿環同態；商環中係數 < N 精確；
       理想 I ⊇ (t^N) 與商環子環之間由標準 Galois 對應聯繫。
    L4 極性矩陣／楚空間公理：物件與屬性為二元矩陣之列／行；轉置為鏡像對偶；
       關係複合由布林矩陣乘法給出；沿索引映射之 Kan 擴展為纖維上的和／積。
    L5 有限域算術公理：模 p 運算以 Int64 + 擴展歐幾里得求逆；GF(2) 線性代數以
       UInt64 位元打包 + 消去法，對應硬體層級常數優化。
  形式化層：src/axioms 以 proof_enabled = true、.mbtp predicate/lemma、
    proof_require/proof_ensure 交予 Z3  discharge（非 stub、非空命題）。
